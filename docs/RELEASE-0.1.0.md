# 村庄铃铛 0.1.0 预览版

适用于 Android 8.0 及以上。下载 `village-bell-0.1.0.apk`，传到手机安装。

使用步骤：游戏中导出村庄数据 → APP 粘贴或选择 JSON/TXT → 确认导入 → 「提醒」页允许通知与准时提醒 → 发送 10 秒测试提醒。

支持建筑、英雄、兵种、法术与战宠的升级计时，以及夜世界升级。数据仅保存在本机。

这是依赖主动导出的离线工具，不会持续同步游戏。新升级、药水、助手或立即完成后需重新导入。包含未校准加速或自动助手的快照暂不安排到点提醒。

APK 编译、签名校验和解析测试通过，尚未完成实机界面、锁屏通知及重启恢复验证。附带 SHA-256 文件用于核对下载完整性。

此 APK 使用开发签名。GitHub Actions 的构建会生成临时密钥，其 APK 与这里的下载版本不保证能相互覆盖安装；日常试用请使用同一发布渠道。
