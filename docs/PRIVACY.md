# 数据与隐私

应用没有网络权限，不连接游戏服务器，不上传村庄数据，也不需要游戏密码或 Supercell ID 登录。

仅在用户主动粘贴、选择文件或分享时读取数据。村庄快照、提醒开关、提前提醒与免打扰偏好、搜索筛选及已通知记录保存在应用私有存储中；系统云备份已关闭。在「指南」中可清除村庄数据并取消升级提醒，卸载应用也会清除数据。

游戏图片来自随安装包提供的离线素材，不联网下载。添加桌面小组件后，桌面会显示升级名称、预计完成时间与数据导出时间；清除村庄数据会同步清空组件内容。演示村庄不保存，也不会写入组件。

通知内容可能出现升级项目名称。应用将通知标记为私密，但具体锁屏展示由系统设置决定。

本仓库的 `tests/fixtures/village-demo.json` 为人工合成数据。真实村庄导出、账号标签、签名密钥、SDK 和构建产物不进入 Git 历史。APK 通过 Releases 单独分发。
