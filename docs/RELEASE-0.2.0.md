# 村庄铃铛 0.2.0 · 村庄可视化

新增原创村庄插画、分类图标、七日完成图表、任务进度条和完成时间轴，统一为羊皮纸与森林绿风格。首次打开可进入演示村庄体验，演示任务不会触发升级提醒。

继续通过游戏导出的 JSON 同步数据。进度条表示导出数据之后的等待进度；村庄插画是主题装饰，不代表实际阵型。

适用于 Android 8.0 及以上，沿用 0.1.0 的本机开发签名，可覆盖安装。安装包为 `village-bell-0.2.0.apk`，附带 SHA-256 校验文件。

26 项解析检查、12 项可视化计算检查与 APK 签名验证通过，已在 Android 10 模拟器安装并检查界面。锁屏、重启恢复及厂商省电策略仍需真机验证。
